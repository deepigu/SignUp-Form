# SignUp-Form
# Overview

This project is a simple signup form that includes a smooth right-to-left transition effect when switching between states. It is built using HTML, CSS, and JavaScript.

# Features

Responsive design

Animated form transition from right to left

Interactive UI with hover effects

Input fields for name, email, and password

Social media icons for alternative signups

# Files Structure

index.html: Contains the structure of the signup form

style.css: Defines the styles and transitions

script.js: Handles the interactive behavior

# How to Use

Open index.html in a browser.

Click the Sign Up button to trigger the animation.

Enter your name, email, and password.

Submit the form (you can extend it with a backend for processing).

# Customization

Modify style.css to change colors, fonts, or animations.

Update script.js to enhance functionality or add validations.

# Dependencies

FontAwesome for icons

Google Fonts (Quicksand)
